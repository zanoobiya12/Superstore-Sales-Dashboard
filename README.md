Superstore Sales Dashboard

📊 Project Overview

Created an interactive **Superstore Sales Dashboard** to analyze sales performance across different categories, regions, states, customers, and time periods.

The dashboard provides a clear visual overview of key sales metrics and helps identify sales trends and regional/category performance.

🛠️ Tools Used

- Power BI
- Data Visualization
- Data Analysis
- DAX
- Power Query

📌 Dashboard Features

KPI Cards
- Total Sales – 2.26M
- Total Orders – 9.8K
- Total Customers – 793
- Total Products – 1.849K
- Average Sales per Customer – 2.85K

Visualizations
- Top Sales by State
- Sales by Region
- Sales by Category
- Sales Trend Over Time
- Sales by State – Map Visualization

Interactive Filters
- Year
- Category
- Region

These filters allow users to interact with the dashboard and analyze the data based on different selections.

🎯 Key Objectives

- Analyze overall sales performance
- Identify high-performing states
- Compare sales across regions
- Analyze category-wise sales
- Understand sales trends over time
- Provide an interactive and easy-to-understand sales overview
